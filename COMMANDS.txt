ETF Trader — Commands Reference
================================


ONE-TIME SETUP
--------------

  git clone <your-repo-url> etf-trader
  cd etf-trader
  cp .env.example .env
  npm install
  npm install --prefix web
  npm run paper:status
  npm run backfill:once

  git clone <your-repo-url> etf-trader
    Clone the project. Does not include .env, market.db, or local state files.

  cd etf-trader
    Enter the project directory.

  cp .env.example .env
    Create local config. Add Alpaca keys and trading flags (or copy an existing .env).

  npm install
    Install backend/CLI dependencies (tsx, better-sqlite3, Alpaca SDK, etc.).

  npm install --prefix web
    Install Next.js dashboard dependencies.

  npm run paper:status
    Verify Alpaca connection. Prints paper account cash, buying power, positions,
    and market clock.

  npm run backfill:once
    Download daily bars for all 30 ETFs into data/market.db. First run is slow;
    later runs fetch only missing days. Skip if you copied market.db.


DAY-TO-DAY OPERATION
--------------------

  npm run dev:web
  npm run automate

  npm run dev:web
    Start the dashboard at http://localhost:3000. Signal, holdings, and Paper
    Automation panel.

  npm run automate
    Start the scheduler daemon. Polls every 60s; when automation is Turn On, runs
    weekday jobs: backfill 4:00 PM -> signal 4:05 PM -> trade 9:35 AM ET. Leave
    running in a terminal.

  Dashboard equivalents:
    Start Scheduler     -> npm run automate
    Stop Scheduler      -> stop the automate process (Ctrl+C or UI)
    Turn On / Turn Off  -> toggle whether scheduled jobs run
    Update Market Data  -> incremental backfill (same as backfill:once)
    Run Signal Now      -> npm run signal
    Preview Trade       -> npm run paper:trade
    Execute Trade       -> npm run paper:trade -- --execute

  Hands-off checklist:
    1. npm run dev:web
    2. npm run automate
    3. Turn On in the dashboard
    4. Set PAPER_TRADING_ENABLED=true in .env for real paper orders at 9:35 AM
       (otherwise 9:35 AM is dry-run only)


MANUAL WORKFLOW
---------------

  npm run backfill:once
  npm run signal
  npm run paper:trade
  npm run paper:trade -- --execute
  npm run paper:status
  npm run automate:tick

  npm run backfill:once
    Step 1 — data. Fetch missing daily OHLCV bars into SQLite. No signal update,
    no orders.

  npm run signal
    Step 2 — signal. Run aggressive dual-momentum on SQLite; write
    data/signal-state.json. No orders.

  npm run paper:trade
    Step 3 — preview. Compare signal to Alpaca paper account; print planned
    sells/buys. Dry-run only.

  npm run paper:trade -- --execute
    Step 4 — execute. Submit market orders to Alpaca paper. Requires
    PAPER_TRADING_ENABLED=true in .env.

  npm run paper:status
    Read-only Alpaca account and market status check.

  npm run automate:tick
    Run one scheduler check immediately (backfill/signal/trade if due and
    automation is on). For debugging.

  Paper trade flags:
    --execute   Submit real paper orders (requires PAPER_TRADING_ENABLED=true)
    --offline   Preview trade plan without calling Alpaca API

  Example:
    npm run paper:trade -- --offline


DATA & MAINTENANCE
------------------

  npm run backfill
  npm run backfill:universe
  npm run backfill:once:5m
  npm run aggregate:daily
  npm run scan
  npm run journal

  npm run backfill
    Targeted historical backfill for specific symbols, timeframe, and date range.
    Lower-level than backfill:once.

  npm run backfill:universe
    Backfill focused on the ETF universe configuration.

  npm run backfill:once:5m
    One-time 5-minute bar backfill for a fixed date range (research/setup).

  npm run aggregate:daily
    Aggregate local intraday data into daily bars in SQLite.

  npm run scan
    Scan SQLite for data coverage and gaps across symbols.

  npm run journal
    Generate daily strategy journal/report.

SCHEDULED AUTOMATION (WEEKDAYS ET)
----------------------------------

  When npm run automate is running and automation is Turn On:

  4:00 PM ET   Backfill   Download missing daily bars
  4:05 PM ET   Signal     Compute momentum signal
  9:35 AM ET   Trade      Dry-run preview, or live paper orders if
                          PAPER_TRADING_ENABLED=true


MOVING TO ANOTHER MACHINE
-------------------------

  Copy these files:

    .env                         Required — Alpaca keys and trading flags
    data/market.db               Optional — skip re-download (~152 MB; use scp/rsync)
    data/signal-state.json       Optional — last computed signal
    data/automation-state.json   Optional — automation on/off, schedule, run history

  If you don't copy market.db:

    npm run backfill:once

  Important:
    Run automation on ONE machine only. Two machines with the same .env and
    automation On can duplicate scheduled trades on the same Alpaca paper account.

    Stop the scheduler on the old machine before starting it on the new one
    (Stop Scheduler in the UI, or Ctrl+C the automate terminal).
